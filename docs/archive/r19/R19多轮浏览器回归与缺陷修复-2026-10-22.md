**两点方法论提醒**：

1. **`5xx` 不能用裸正则匹配日志行** —— 十六进制 `traceId` / 时间戳 / 端口号都会命中。要么锚定 `HTTP 5\d\d` 这类带前缀的形态，要么先按字段解析 JSON。本轮 `portal-server` 8 条假阳性就是这么来的。
2. **H1 缺陷的 401 不会出现在应用日志里** —— `/auth/permissions` 的 401 由 nginx / 网关直接返回，应用容器 `docker logs` 里是 0 条。**证明「探针 401」必须看浏览器 Network 层或 nginx access_log**，用容器日志找不到，这一点很容易把「有缺陷」误判成「没问题」。

**附带观察（未登记为待办）**：`kb-gateway` 对**客户端可控输入**（垃圾 `Bearer`）打 `ERROR` 级日志。恶意方可用无效 token 刷日志量（日志放大）。当前量级无害，若未来做日志成本治理，可考虑把「RS256 头解析失败 + HS256 回退失败」降为 `WARN` 并对同源同 IP 做聚合。

## 3 缺陷与订正

### 3.1 【真缺陷·已修】R19-D1 登录页（无票）仍发起权限探针 → 401 噪声 + 潜在 fail-open 窗口

**现象**（H1 硬证据，2/2 轮复现）：

```
GET https://kb.marschat.online/ops-api/auth/permissions?client=marschat-kbops   => 401
GET https://monitor.marschat.online/infra/api/auth/permissions?client=marschat-inframon => 401
console: Failed to load resource: the server responded with a status of 401
```

**根因**：`@marschat/app-kit` 的 `bootstrap()` 只判 `prefetchPermissions !== false`，
**不看本地有没有令牌** ⇒ 登录页（未登录）也会打一发权限探针。
portal / kb-web 之所以没暴露，是因为它们**恰好**把 `marschat.bootstrap()` 包在 `if (token)` 里 ——
**靠人自觉**，不是靠机制（这正是本项目最反对的形态）。

**两个后果**（都属于「不报错但坏」）：

1. 控制台 + 监控侧噪声：每个 kb-ops / infra 用户每次访问登录页，监控就多一条 401 失败率；
   排障时还会被误读成「权限链又断了」（T-ENG-17 的现场观感）。
2. **潜在越权窗口**：`fetchPermissions` 成功即写 `lastFetchedAt`；若某应用后端**匿名**就回了
   `200 + configured:false`，这份「未配置」会在 **60s** 内被登录后的守卫/菜单复用 ⇒ 菜单级限制全放行。

**修复**（`@marschat/app-kit` **0.1.9**，本仓 `packages/app-kit`）：

```ts
// config.ts（纯函数，可单测）
export function shouldPrefetchPermissions(options, hasToken) {
  if (options && options.prefetchPermissions === false) return false
  return !!hasToken            // 🔴 无票不探
}
// createMarschatApp.ts
if (shouldPrefetchPermissions(options, !!getToken())) { void ensurePermissions(permissions)... }
```

- 语义：显式 `false` 最优先；**显式 `true` 也越不过「无票」闸门**；有票时行为与 0.1.8 逐字一致。
- 单测 **229 → 238**，含两个变异体自证（「只判配置」与「恒不探」都被断言抓住）。

### 3.2 【真缺陷·已修】R19-D2 脚手架生成的骨架「照抄必踩」

`scripts/scaffold-app.mjs` 是「新应用接入只改配置」的唯一入口，实测它生成的骨架**缺 4 项必传、缺 2 份配置**：

| 2 | 未传 `watchSession` | 双模应用（账密+SSO）缺省按纯 OIDC 处理 ⇒ 账密会话重载后 **3 秒被踢**（坑 #47，infra / kb-ops 各一次） |
