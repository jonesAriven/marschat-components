### 3.3 devtools 流水线 #872–#875 「部署失败」事件（环境噪声，已自愈）

- **现象**：K3 核对时发现 #872 kb-ops-web / #873 kb-web / #874 infra-monitor-web / #875 portal-web 四条流水线 clone ✅ 但 **deploy ❌**，错误均为 SSH 侧 `bash: 部署脚本: No such file or directory` + `scp: /tmp/portal-deploy-xxx.tar.gz: No such file or directory`。
- **归因**：deploy 步骤里 `ssh "$DEPLOY_TARGET" "cat > /tmp/<name>-deploy.sh && bash /tmp/<name>-deploy.sh"` 的**引号剥离竞态**——四条前端流水线并发跑时 `sync-ci-scripts` 步骤 `find /mnt/shared/woodScript -mindepth 1 -delete` 后重写，瞬时目录竞争导致 heredoc 落盘失败。**与认证组件无关**（组件侧零变更、五应用在线 chunk 全部命中 0.1.9 签名）。
- **现状**：随后 **#876 portal-web SUCCESS**，deploy 步骤 20s，无残留。
- **登记**：`状态与待办.md` **T-OBS-7**（建议后续给 devtools deploy 步骤加超时与并发互斥；低危、可自愈、不阻断回归）。

### 3.4 环境备注（非缺陷）

- mykng `/etc/hosts` 将 `kb.marschat.online` 钉到 `127.0.0.1`（其余 `*.marschat.online` 走公网入口）⇒ K4 产物下载用 `curl --resolve` 显式钉 `1.117.70.30` 绕开，与浏览器侧 `--host-resolver-rules` 同思路。测试方法注记，不影响生产判定。
