## 测试用例清单

### TC-001: 独立登录页面检查
**前置条件**: 无
**测试步骤**:
1. 访问系统登录页
2. 检查是否存在用户名输入框
3. 检查是否存在密码输入框
4. 检查是否存在登录按钮
5. 检查是否存在"忘记密码"链接
6. 检查是否存在 SSO 登录按钮

**预期结果**: 
- 用户名/密码输入框存在且可输入
- 登录按钮可点击
- "忘记密码"链接存在且指向正确地址
- SSO 按钮存在（除 tokenhub 外）

**适用系统**: Portal, kb-web, kb-ops, infra-monitor, tokenhub

---

### TC-002: 忘记密码功能检查
**前置条件**: 在登录页
**测试步骤**:
1. 找到"忘记密码?"链接
2. 点击链接
3. 检查跳转目标是否为 auth-center 忘记密码页

**预期结果**: 
- 链接跳转到 `https://auth.marschat.online/forgot-password.html` 或类似地址
- 页面可正常加载

**适用系统**: 所有需要登录的系统

---

### TC-003: SSO 按钮功能检查
**前置条件**: 在登录页
**测试步骤**:
1. 找到 SSO 登录按钮（如"统一认证登录(SSO)"）
2. 点击按钮
3. 检查是否跳转到 auth-center 授权页面

**预期结果**: 
- 跳转到 `https://auth.marschat.online/oauth2/authorize?...` 或 `https://auth.marschat.online/login`
- URL 包含正确的 client_id 和 redirect_uri

**适用系统**: Portal, kb-web, kb-ops, infra-monitor

---

### TC-004: SSO 完整流程（含账密输入）
**前置条件**: 已点击 SSO 按钮跳转到 auth-center
**测试步骤**:
1. 在 auth-center 输入用户名
2. 在 auth-center 输入密码
3. 点击 Sign in 按钮
4. 检查是否回调原系统
5. 检查是否自动完成登录

**预期结果**: 
- auth-center 认证成功
- 回调原系统并携带 code
- 原系统换取 token 成功
- 自动跳转到 dashboard

**适用系统**: Portal, kb-web, kb-ops, infra-monitor

---

### TC-005: 独立登录功能
**前置条件**: 在登录页
**测试步骤**:
1. 输入用户名
2. 输入密码
3. 点击登录按钮
4. 检查登录结果

**预期结果**: 
- 登录成功跳转到 dashboard
- 或显示具体错误信息（账号密码错误等）

**适用系统**: Portal, kb-web, kb-ops, infra-monitor, tokenhub
