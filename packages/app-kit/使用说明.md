# @marschat/app-kit 使用说明

> **定位**：本包是 MarsChat 应用接入的**装配层（推荐入口）**——引入本包 + 写少量配置，即获得统一登录（SSO / 账密 / 邮箱码 / 忘记密码）、统一鉴权（RBAC 三层同源）、单点登出联动、「本系统用户」管理页。
> **配套文档**：设计原理与完整接入手册见 `docs/统一认证平台手册.md`（设计 · 接入 · 使用运维三篇）；配置字段全表见 `docs/配置参考.md` §5.2；决策记录见 `docs/Phase13-配置化接入.md`。
> **版本基线**：0.1.9（2026-10-22，无令牌不预取权限）。

---

## 1. 快速开始

```ts
// main.ts —— 全部前端接入代码
import { createApp } from 'vue'
import { createMarschatApp } from '@marschat/app-kit'
import App from './App.vue'
import { router, menus } from './setup'

const app = createApp(App)
const marschat = createMarschatApp({ appId: 'marschat-xxx', router, menus })

marschat.install(app)          // 必须早于 mount：注册 /login /sso-callback /users 路由
app.use(pinia); app.use(ElementPlus)
app.mount('#app')
marschat.bootstrap()           // 挂载后：会话监视 + 权限预取（幂等）
```

配套后端（`com.marschat:auth-core` 自动装配，同样只需配置）：

```yaml
marschat:
  bff:
    enabled: true
    client-id: marschat-xxx
```

再加一份 `bff-whitelist.yml`（管理代理白名单，默认拒绝）。三处配置 + 一行装配的完整说明见 `docs/统一认证平台手册.md` 第二篇。

## 2. `createMarschatApp(options)` 字段

必填只有两项：`appId` 与 `router`。其余均有默认值。

| 字段 | 默认 | 说明 |
|---|---|---|
| `appId` | — | **必填**。client-id，须与 `apps-registry.yml` 一致 |
| `router` | — | **必填**。vue-router 实例（结构性契约，不 import vue-router） |
| `menus` | — | 本应用菜单定义，**唯一必须手写的业务数据**；由 `useMenus` 按权限过滤 |
| `runtime` | 自动读 `public/app-config.json` | 运行时配置 |
| `permissionsIssuer` | `resolvePermissionsIssuer()` 派生 | 🔴 权限查询基址。门户类应用（portal / cosmic）必须指向同源代理 `apiBase`；**不要**把 BFF 基址塞进 `issuer`（会静默废掉免登与 SLO） |
| `origin` | `window.location.origin` | 当前站点 origin |
| `loginPage` | — | 登录页外观（title / subtitle / color / icon / layout / `showLocalLogin` / `showMailLogin` / `showForgotPassword` / footerText，其余透传 LoginPageConfig） |
| `userManagement` | — | 用户管理页（`scopeMode: 'app' \| 'platform'`、roles、readonly、allowDelete、allowResetPassword 等） |
| `autoRoutes` | `true` | 自动注册 `/login` `/sso-callback` `/users` |
| `prefetchPermissions` | `true` | 🔴 0.1.9 起**无令牌不预取**（`shouldPrefetchPermissions`）；本字段只用于额外关闭 |
| `clearExtraAuth` | — | 🔴 清理「令牌四键之外」的应用自管会话残留（登出 / 401 / 会话丢失时调用，须幂等）。不清 = 共用浏览器上权限信息泄漏 |
| `watchSession` | `true` | 🔴 会话监视判据。**双模应用（账密 legacy + SSO oidc 并存，如 kb-web / portal）必须传 `() => isOidcToken()`**，传 `true` 会把账密用户 3 秒后误踢回 `?slo=1`；纯 BFF 单模应用不要传函数 |
| `afterLoginRedirect` | `homePath` | 登录成功落地页 |

完整字段与派生规则（`sessionMode` 闸门、令牌四键派生、运行时配置候选优先级）见 `docs/配置参考.md` §5.2 与 `docs/统一认证平台手册.md` 坑表 #5 / #40 / #42。

## 3. 返回值句柄

| 句柄 | 用途 |
|---|---|
| `marschat.config` | 派生后的最终配置——排查「配置到底生效了没」的**唯一依据** |
| `marschat.sso` | SSO 客户端：`login` / `handleCallback` / `renew` / `logout` / `watchSession` / `decodeClaims` |
| `marschat.request` | 统一请求实例（业务 `request` + 认证 `authRequest`，已带 401 续期分流） |
| `marschat.permissions` | 权限选项，直接喂给 `usePermissions` / `useMenus`（三层同源） |
| `marschat.install(app)` | 挂载到 Vue 应用，**必须**在 `app.mount()` 前调用 |
| `marschat.bootstrap()` | 挂载后启动会话监视 + 权限预取（幂等） |
| `marschat.createShell(overrides?)` | 创建共享应用外壳（侧边栏 + 顶栏 + 内容区），消除各应用自写 MainLayout |

宿主用法：`<component :is="marschat.createShell()" />`。

## 4. 共享外壳 `createShell()`

```vue
<component :is="marschat.createShell()" />
```

`ShellOptions` 支持覆盖标题 / 品牌 / 页脚等；`router` / `menus` / `permissions` 由装配层注入，不需要传。样式常量 `SHELL_CSS` 一并导出。

## 5. 纯函数导出（测试 / 高级用法）

除装配入口外，本包导出全部关键纯函数，便于单测与定制：

- 运行时配置：`readRuntimeConfig` / `loadRuntimeConfig` / `runtimeConfigCandidates` / `parseRuntimeConfig` / `formatRuntimeConfigWarning`
- 权限预取：`buildPermissionsUrl` / `classifyPermissionsFailure` / `shouldPrefetchPermissions` / `formatPermissionsWarning` / `warnPermissionsFailure` / `createPermissionsWarnDedupe` / `resetPermissionsWarnDedupe` / `PERMISSIONS_FAIL_OPEN_CONSEQUENCE`
- 配置派生：`resolveAppConfig` / `resolvePermissionsIssuer` / `normalizeContextPath` / `baseFragment` / `deriveTokenKeys` / `mergeTokenKeys` / `appUrl` / `toRouterPath` / `DEFAULTS` / `DEFAULT_WHITE_LIST_PATHS`
- 类型：`RuntimeConfig` / `PermissionsResponseLike` / `MarschatAppOptions` / `LoginPageOptions` / `UserManagementOptions` / `SessionMode` 等
